# Mail CLI v0.1 执行计划

## 目标

- 满足验收标准：Exmail 稳定完成列信、读信、搜索、发信、附件下载。
- 核心命令支持 `--output json`。
- 新用户 5 分钟内完成安装与首次连通性测试。

## 工作包（仅规划，不含实现）

1. 基础工程
   - CLI 框架（命令分组、全局参数）
   - 配置加载（路径、校验、默认账号）
   - 错误与输出基类（plain/json）

2. 连接与诊断
   - IMAP/SMTP 连接器封装
   - `account diagnose`（认证、网络、端口、TLS）

3. IMAP 主链路
   - `envelope list`
   - `envelope search`
   - `message read`
   - `attachment download`

4. SMTP 主链路
   - `message send`（文本邮件）
   - 后续扩展：HTML、多附件、reply/forward

5. 稳定性与测试
   - 核心流程测试：list/read/search/send
   - 异常测试：认证失败、超时、文件夹不存在

6. 交付体验
   - README 快速上手
   - 最小发布验证（本地 pip/pipx 安装）

## 建议里程碑

- M1：CLI + 配置 + 诊断
- M2：IMAP list/read/search
- M3：SMTP send + attachment
- M4：测试与 README

## 风险与应对

- Exmail 兼容细节差异：通过 `quirks` 配置隔离提供商差异。
- 网络与超时不稳定：默认超时、重试策略、可见错误提示。
- 输出格式漂移：统一输出层，命令结果统一序列化。
